# 果仓助手 (AppleVault) v1.7.0 更新说明

果仓助手 (AppleVault) v1.7.0 重点优化了 **设备安装控制**、**下载排队与取消体验**、**macOS 密码加密保护** 以及 **日常使用的流畅度与稳定性**，让下载和安装正版应用更省心、更可靠。

---

## 🌟 主要更新

### 1. 📲 设备安装更好用
- **支持随时取消安装**：在「设备直装」页面新增了「取消安装」按钮。装机过程中切换账号或搜索其他应用不再误中断安装，同时防止误点重复启动多个安装任务。
- **iPad 支持安装 iPhone 专属应用**：此前仅适配 iPhone 的 IPA 在 iPad 上会被判定不兼容，现在允许在 iPad 上以兼容模式正常安装，并在安装前给出明确提示。

### 2. ⬇️ 下载更稳定、管理更省心
- **自动排队与并发控制**：同时最多进行 2 个下载任务，超出数量的任务会自动排队并显示「排队等待中」，避免同时下载过多拖慢网速或导致失败。
- **取消响应更快、自动清理残余文件**：搜索、查历史版本、下载及校验安装包时点击取消都会立即生效；下载取消或出错后会自动清理未完成的临时文件，避免白占硬盘空间。
- **多历史版本不再互相覆盖**：下载同一应用的不同历史版本时，保存的文件名会自动区分版本编号并过滤特殊字符，避免覆盖旧包或保存失败。
- **历史记录更清晰、兼容 macOS 安装包**：下载记录新增完整日期显示，并自动保留最近 200 条历史记录（不影响正在下载的任务）；同时修复下载 macOS 应用安装包（`.pkg`）时误走 IPA 处理的问题。

### 3. 🔒 账号安全与多区显示更贴心
- **macOS 密码加密保护**：在 macOS 上，本地配置的钥匙串密码现已由系统钥匙串加密保护，不再以明文保存，且仅限本机使用不会同步到 iCloud。
- **多地区货币正确显示**：搜索和浏览美区、港区、日区等其他地区 App Store 时，付费应用价格会按对应货币符号准确显示，不再一律显示人民币符号。
- **新安装默认关闭代理**：首次启动默认不开启本地代理，避免未开启代理软件时直接无法联网；手动填写代理地址时也会提前校验格式，出错原因更明确。
- **移除账号更彻底**：删除账号时会自动先停止该账号正在进行的下载任务，再清理相关登录信息。

### 4. ✨ 细节体验与稳定性修复
- **不错过启动提示**：程序刚启动时产生的提示日志会自动保留，打开后在底部状态栏即可完整查看。
- **切换账号与设备平台不串数据**：快速切换账号或更改 iPhone / iPad 平台时，搜索结果、已购列表和历史版本页面会及时刷新与重置，避免把上一个账号或平台的数据错显出来。
- **修复 Windows 打开文件位置失败**：当下载目录或应用名包含空格时，点击打开所在目录现在可以正常在资源管理器中选中文件。
- **更稳妥的配置与缓存保存**：优化 Windows 下配置文件与任务列表的保存方式，降低异常退出或杀毒软件占用时损坏文件的风险；减少查询历史版本时的频繁读写硬盘，整体运行更流畅。

## 📦 安装与签名说明
- **Windows (`AppleVault-v1.7.0-windows-amd64.zip`)**：解压后直接运行 `AppleVault.exe` 即可，内置 `tools/ios.exe` 设备安装工具，个人数据保存在同目录 `data/` 下。
- **macOS (`AppleVault-v1.7.0-macos-universal.dmg` / `.zip`)**：将 `AppleVault.app` 拖入「应用程序 (`Applications`)」文件夹。由于未使用 Apple Developer ID 公证，首次打开如提示「无法验证开发者」或「已损坏」，在终端执行以下命令后重新打开即可：
  ```bash
  sudo xattr -cr /Applications/AppleVault.app
  ```
- 下载后建议对照 `SHA256SUMS.txt` 校验安装包哈希完整性。
