# 果仓助手 (AppleVault) v1.5.0 更新说明

果仓助手 (AppleVault) v1.5.0 是一次以**恢复 Apple ID 登录**为核心的稳定性更新。Apple 近期调整了 App Store 认证机制，旧版本登录时会出现 `HTTP 204 / 404 empty or non-plist body` 等错误而无法登录。本版本将内置的 App Store 模块整体升级到 ipatool v2.8.1 的新认证流程，并针对国内网络环境做了专门适配。

---

## 🌟 主要更新

### 1. 🔐 修复 Apple ID 无法登录
- **全新认证流程**：内置 App Store 模块升级至 ipatool v2.8.1，采用本地生成的设备身份（Anisette）与 Apple 最新的认证协议，恢复登录、购买与下载能力。
- **国内网络适配**：
  - 内置 Apple Root CA 根证书（SHA-256 指纹校验），解决 Windows 系统默认不信任 Apple 认证服务器、且国内无法下载该证书（HTTP 403）导致的登录失败。证书仅在本程序的认证请求中使用，**不会修改系统证书**。
  - 内置 App Store 地区表，在 Apple 地区列表接口不可用（HTTP 404）时自动回退，避免搜索、版本查询与下载失败。
- **首次登录提示**：首次登录需要准备认证组件（下载并缓存所需的系统组件），可能需要几分钟，界面会给出相应提示，之后登录会快很多。

### 2. 🔑 双重认证登录体验优化
- **修正误导性的验证码弹窗**：Apple 对“密码错误”和“需要验证码”返回的是同一种响应，旧版本在输错密码时也会跳到验证码界面。现在统一提示“Apple ID 或密码错误；若受信任设备收到了验证码，请填入后重新登录”。
- **验证码直接填在登录表单中**：移除了单独的验证码弹窗，在“添加 Apple ID”窗口中新增可选的“双重认证验证码”输入框；登录失败时保留已填写的账号和密码，并自动聚焦到验证码输入框。
- **验证码错误提示**：验证码错误或已过期时，明确提示重新获取新的验证码。

### 3. 📲 修复安装 IPA 时被其他操作打断
- 修复了在向设备安装 IPA 的过程中，如果同时查询应用版本（或执行其他商店操作），安装会被直接中断失败的问题。现在安装任务独立运行，只有用户主动点击“取消”时才会停止。

### 4. 🛡️ 保留并沿用的能力
- 应用设置中的网络代理继续对登录、购买、下载等商店请求生效。
- 下载完成后的 MD5 与 IPA 完整性校验、历史版本查询与 IPA 文件大小显示均保持可用。

---

## ⚠️ 升级说明
- 由于认证机制变更，升级后**需要在账号中心重新登录一次** Apple ID。
- 若账号开启了双重认证：第一次点击登录后，受信任设备会收到验证码，将其填入“双重认证验证码”栏后再次登录即可。
- 若受信任设备没有弹出验证码，可在 iPhone 上前往 **设置 → 你的名字 → 登录与安全 → 获取验证码** 手动获取。
