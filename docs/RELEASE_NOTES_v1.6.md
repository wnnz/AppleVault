# 果仓助手 (AppleVault) v1.6.0 更新说明

果仓助手 (AppleVault) v1.6.0 重点围绕 **历史版本查询提速**、**macOS 正式适配与双平台打包** 以及 **下载任务稳定性与本地凭据安全加固** 进行了全面优化。

---

## 🌟 核心更新

### 1. ⚡ 历史版本「查详情」大幅提速
- **CDN Range 请求直连化**：分片读取远程 IPA 时不再反复冷启动嵌入式 ARM64 虚拟机，直接通过复用的 Keep-Alive 连接池发起传输与重定向请求。
- **预取合并 ZIP 中央目录与 `Info.plist`**：一次探测总大小与 ZIP 尾部后直接合并预取中央目录及 `Info.plist` 所在区间，将大型应用原本上百次的 4 KB 串行请求压缩至 1–3 次。
- **会话与钥匙串全链路加速**：按账号与网络设置复用会话实例与 `urlBag` 缓存，加入写穿式内存钥匙串避免重复 PBKDF2 加解密，并在已掌握 `App ID` 时直接跳过冗余的 iTunes Lookup。
- **历史构建持久化缓存**：新增本地构建详情缓存（`version_metadata_cache.json`），已查询过的版本号、体积与发布日期再次加载或检索时秒级展示；二分查找与批量解析支持失败重试与缓存命中零等待。

### 2. 🍎 macOS 正式适配与双平台自动化发布
- **macOS Universal 通用包**：原生同时支持 Apple Silicon（M 系列）与 Intel Mac，提供 `.dmg` 与 `.zip` 双格式安装包。
- **系统集成与路径兼容**：
  - 支持在 Finder 中直接打开下载目录并高亮定位文件（`open -R`）。
  - macOS 下自动将配置、凭据与下载数据保存在标准的 `~/Library/Application Support/AppleVault` 目录，避免写入只读 `.app` 包内部。
  - 自动探测包内随附的 `go-ios` 设备工具及 Homebrew 安装路径，适配 macOS 单测与设备直装体验。
- **自动发布流水线**：版本分支合入 `main` 后自动并行完成 Windows 与 macOS 双平台编译、测试与 GitHub Release 发布。

### 3. 🛡️ 下载队列、安装体检与数据安全加固
- **下载状态机修复与平台绑定**：修复删除下载中任务后列表复活、同应用同版本重复入队冲突以及排队态取消竞态等问题；下载任务独立记录目标平台，重试时准确沿用原平台。
- **单实例锁与安全退出保护**：防止重复启动多个桌面端实例；存在活跃下载任务时关闭窗口会弹出确认提示，确认退出后自动中止并安全保存状态。
- **快速 IPA 检测与可取消校验**：拖入或选择本地 IPA 时秒级读取基础元数据，耗时的全量 ZIP 条目完整性校验移至点击安装前执行且支持中途取消。
- **本地凭据加密与原子写入**：Windows 端钥匙串主密码改用系统 DPAPI 加密保护并自动迁移旧明文；`settings.json`、`tasks.json`、`accounts.json` 全部采用原子写盘并在文件损坏时自动备份；自动清理 14 天前的诊断日志并对隐私字段上限脱敏。

### 4. ✨ 交互细节与稳定性修复
- 修复搜索页、下载中心与「默认下载平台」联动，补全应用内平台透传。
- 修复账号移除在网络代理配置失效或凭据缺失时报错阻塞的问题，切换或退出当前账号时自动同步清空跨视图状态。
- 清理冗余资源文件与无效界面绑定，修复状态栏文案、表格提示文本及手绘主题细节问题。

## 📦 安装与签名说明
- **Windows (`AppleVault-v1.6.0-windows-amd64.zip`)**：解压后直接运行 `AppleVault.exe` 即可，内置 `tools/ios.exe` 设备安装工具，个人数据保存在同目录 `data/` 下。
- **macOS (`AppleVault-v1.6.0-macos-universal.dmg` / `.zip`)**：将 `AppleVault.app` 拖入「应用程序 (`Applications`)」文件夹。由于未使用 Apple Developer ID 公证，首次打开如提示「无法验证开发者」或「已损坏」，在终端执行以下命令后重新打开即可：
  ```bash
  sudo xattr -cr /Applications/AppleVault.app
  ```
- 下载后建议对照 `SHA256SUMS.txt` 校验安装包哈希完整性。
